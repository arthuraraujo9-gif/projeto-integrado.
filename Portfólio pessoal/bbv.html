Sobre Mim

Olá, Sou estudante do curso técnico de Informática e estou imergindo no universo do desenvolvimento de software. Atualmente, meu foco principal é compreender a arquitetura web através da criação e estruturação de dados utilizando HTML5, em conjunto com a estilização e responsividade visual fornecidas pelo CSS3.

Busco transformar linhas de código em interfaces organizadas, agradáveis e funcionais, evoluindo a cada aula prática e projeto desenvolvido.

Objetivos Profissionais

Meu principal objetivo no momento é consolidar uma base sólida em lógica de programação. No futuro, pretendo ingressar no mercado de trabalho como desenvolvedor de software, colaborando em grandes projetos e aplicando tecnologia para resolver problemas reais do cotidiano.

O que estou Aprendendo

  • Estruturação Avançada: Conceitos fundamentais e tags semânticas do HTML5 para melhor acessibilidade.
  • Estilização Moderna: Manipulação de cores, fontes, layouts elásticos, paddings, margens e efeitos dinâmicos com CSS3.
  • Versionamento de Código: Uso inicial de Git e plataforma GitHub para gerenciar e hospedar códigos com segurança.
  • Lógica e Resolução de Problemas: Construção de algoritmos e desenvolvimento do raciocínio analítico computacional.
